单文件、零第三方依赖的 Windows 原生 GUI 工具，通过修改 `libcc.dll` 中内嵌 RSA 公钥的一个字符，
使离线激活校验使用可分解的模数，从而生成对应的离线激活码。

## 功能特性

- **单窗口、左右两栏界面**：左侧按“检查 → 补丁 → 离线激活”三步操作，右侧显示当前状态与日志。
- **自动检测安装目录**，并在标题旁标注来源：
  - 程序所在目录、当前工作目录
  - 桌面 / 公共桌面 / 用户与所有用户的开始菜单快捷方式（解析 `.lnk` 目标）
  - 默认安装路径（`Program Files`、`Program Files (x86)` 及对应环境变量）
  - 各盘根目录及其下的 `Navicat*` / `PremiumSoft*` 目录
- **资源管理器风格的目录选择**（`IFileOpenDialog` + `FOS_PICKFOLDERS`）。
- **单字节补丁**：只把公钥下标 364 的 `S`（`0x53`）改为 `T`（`0x54`），不需要额外节区或密钥文件。
- **离线激活码生成**：内置 `N'` 与私有指数 `D`，请求解密与响应签名均带公钥回验。
- **刷新离线激活密钥**：按 DES 短序列号算法生成新的 16 位密钥（自动复制）。
- 备份、补丁、激活都可重复执行，已完成的步骤自动跳过；支持从 `.bak` 恢复原版。

## 工作原理（简述）

1. `libcc.dll` 在运行时逐段拼接一把 392 字符的 RSA 公钥（SPKI Base64）。
2. 把该公钥下标 364 的 `S` 改为 `T`，模数变为：

   ```text
   N' = N + 2^122 = 47 · q
   ```

   由于 `N'` 含小因子 47，可在不分解原公钥的前提下计算：

   ```text
   D = e^(-1) mod ((47-1)(q-1)),  e = 65537
   ```

3. 离线激活请求为 PKCS#1 v1.5 **Type-2** 块：用 `D` 解出 `00 02 PS 00 JSON`，保留请求中的 `K` / `DI` / `P`。
4. 激活码为 **Type-1** 块：`00 01 FF...FF 00 JSON`，用 `D` 做私钥运算并由 `e` 回验。
5. 不同版本只是重新编译后函数位置不同，工具通过以下方式定位补丁点：
   - 优先匹配已知版本的完整 SHA-256；
   - 否则用 MSVC RTTI 名 `.?AVCSRegistrationInfoFetcher_WIN@@` → TypeDescriptor → CompleteObjectLocator → 虚表 `+0x30` 槽找到公钥构造函数；
   - 用 `.pdata` 取得函数范围，匹配“先追加 `R`（`mov dl,52h`）再追加 `S/T`（`mov dl,53h/54h`）”的指令特征，并用 `"Wa"` 立即数 / 下标 `0xC6` 自引用做二次确认；
   - 定位不唯一或失败时**拒绝修改**，避免误改。

已核对的补丁文件偏移：

| 版本 | 文件偏移 | 说明 |
| --- | --- | --- |
| 17.3.6 | `0x21626C5` | 本机实测通过（补丁、激活、重启保持） |
| 18.0.6 | `0x27EC415` | 来自公开分析，未在本机实测 |

## 使用流程

1. 关闭所有 Navicat 进程，建议先断开网络。
2. 以管理员身份运行 `build\navicat-crack.exe`（需要写入安装目录下的 `libcc.dll`）。
3. 选择安装目录（自动检测结果会在“安装目录”标题旁标注来源）。
4. 按界面从上到下操作：
   - **第 1 步 检查状态**：确认 `libcc.dll`、备份与补丁状态。
   - **第 2 步 备份并打补丁**：自动备份为 `libcc.dll.bak` 并写入单字节补丁；旁边的“启动 Navicat”可直接启动程序。
   - **第 3 步 离线激活**：复制/刷新离线密钥，在 Navicat 中获取请求码；粘贴请求码，填写用户名/组织名（默认 `Admin` / `Personal`），生成并复制激活码。

更详细的图文步骤见 `build\使用教程.txt`（本地文件，未纳入版本库）。

### 还原

删除 `libcc.dll`，把同目录的 `libcc.dll.bak` 重命名回 `libcc.dll` 即可。
若检测到旧方案生成的 `.pkey` 节，工具会提示先按上述方式恢复原版。

## 构建

需要 Go 1.21 或更新版本，以及 Windows 环境（纯标准库 + Win32 API，无 cgo）。

```bat
build.bat
```

或手动执行：

```bat
go build -trimpath -ldflags "-H windowsgui -s -w" -o build\navicat-crack.exe .
```

产物为 GUI 子系统（无控制台窗口），输出到 `build\` 目录。

## 已知限制

- 仅支持使用同一把内嵌公钥的版本；若未来版本轮换公钥，内置的 `N'` / `D` 会失效，需要重新分析并更新参数。
- 单字节补丁依赖编译器生成的指令形态；未知版本自动定位失败时会拒绝修改。
- 切换方案后，旧方案（自定义密钥对 / `.pkey` 节）签发的激活数据会失效，需要用本工具重新激活。
- 目前仅提供 Windows x64 版本。
